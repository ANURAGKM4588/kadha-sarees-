# Kadha Sarees — Handwoven E-Commerce Store

Official online store for **Kadha Sarees** — featuring handwoven Kanjivaram, Banarasi, Chanderi, Tussar, Mulmul, and Sungudi sarees.

- **Website**: [https://www.kadha.shop](https://www.kadha.shop)
- **Tech Stack**: React 18, TanStack Start & Router, TypeScript, Tailwind CSS, Supabase, Razorpay.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Features

- **Product Catalog & Details**: High-resolution image galleries, weave filters, price breakdowns, and blouse selection options.
- **Cart & Instant Checkout**: Dynamic bag widget, Razorpay integration, order confirmation system.
- **Responsive Design**: Optimized for desktop, tablet, and mobile browsers.
